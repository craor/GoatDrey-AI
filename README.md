# GoatDrey AI

Настольный помощник для **Windows 10 / 11** и **macOS (MacBook, iMac, Mac mini — Apple Silicon M1–M4 и Intel)**: чат с историей и папками, поиск в интернете, голосовой ввод и озвучка, работа с файлами и картинками, генерация фото и видео и **автономная работа на компьютере**: даёте задачу — GoatDrey сам смотрит на экран, кликает, печатает, работает с файлами и отчитывается. Без подтверждений на каждом шаге, но с жёсткими правилами безопасности.

**В программе нет ни одного встроенного ключа API.** Работает бесплатно через Ollama на вашем компьютере или через ваш собственный ключ любого провайдера.

**Думает там, где скажете:**
- **На вашем компьютере** — через [Ollama](https://ollama.com) или LM Studio. Бесплатно, без интернета и без лимитов. Чем мощнее видеокарта, тем быстрее.
- **Через любой ключ API** — Groq, OpenAI, xAI (Grok), Google Gemini, Anthropic (Claude), OpenRouter, DeepSeek, Mistral, MiniMax, Together или любой OpenAI-совместимый адрес. Ключей можно добавить сколько угодно и переключаться сверху, в списке моделей.

## Установка (рекомендуется)

1. Скачайте **`GoatDrey-AI-Setup-<версия>.exe`** со страницы [Releases](https://github.com/craor/GoatDrey-AI/releases) (или возьмите из `release/` после своей сборки) и запустите.
   - Windows может показать синее окно SmartScreen («Windows защитила компьютер»): у программы нет платной подписи. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
2. Выберите язык установщика, затем **«Только для меня»** (без прав администратора) или «Для всех пользователей».
3. На шаге **«Папка установки»** нажмите «Обзор…» и выберите, куда поставить (по умолчанию `%LOCALAPPDATA%\Programs\GoatDrey AI`). Нажмите «Установить».
4. Готово: ярлыки появятся в **меню «Пуск»** и **на рабочем столе**. Запускайте GoatDrey AI оттуда.
5. Удалить: **Параметры → Приложения → Установленные приложения → GoatDrey AI → Удалить** (переписка и настройки в `%APPDATA%\GoatDrey AI` остаются, если не удалить их вручную).

**Без установки:** `GoatDrey-AI-<версия>-portable.exe` (собирается `npm run dist:win-portable`) — запускается сразу, ничего не ставит, но **сам не обновляется**.

При первом запуске программа спросит **«Где думать?»**:
- **«На этом компьютере» (рекомендуется, по умолчанию)** — бесплатно и без ключей. Установите [Ollama](https://ollama.com/download), и GoatDrey подскажет и скачает модель под ваше железо (см. «Локальные модели» ниже);
- **«Свой ключ API»** — вставьте ключ любого провайдера (Groq, OpenAI, xAI/Grok, Gemini, Claude, OpenRouter…), провайдер определится сам. Ключ хранится только у вас и зашифрован средствами системы.

## Установка на Mac (MacBook)

Подходит для **macOS 11 Big Sur и новее**, на **Apple Silicon (M1, M2, M3, M4)** и на **Intel** — сборка universal, файл один.

1. В релизе на https://github.com/craor/GoatDrey-AI/releases скачайте **`GoatDrey-AI-<версия>-mac-universal.dmg`**.
2. Откройте `.dmg` и перетащите **GoatDrey AI** в папку **«Программы» (Applications)**.
3. **Первый запуск.** У программы нет платной подписи Apple, поэтому macOS её не пустит двойным щелчком. Сделайте одно из двух:
   - в «Программах» **правый клик (или Control+клик) по GoatDrey AI → «Открыть» → «Открыть»**. Дальше запускается как обычно;
   - на macOS 15 Sequoia и новее, если «Открыть» нет: попробуйте запустить, затем **Системные настройки → Конфиденциальность и безопасность →** внизу «GoatDrey AI заблокирован» → **«Всё равно открыть»**;
   - если macOS пишет **«Приложение повреждено и не может быть открыто»** — откройте Терминал и выполните:
     ```bash
     xattr -cr /Applications/GoatDrey\ AI.app
     ```
     (снимает метку «скачано из интернета»), потом запускайте.
4. **Разрешения для режима «Компьютер»** (мышь, клавиатура, скриншоты). **Системные настройки → Конфиденциальность и безопасность**:
   - **Универсальный доступ (Accessibility)** → включите **GoatDrey AI** — без этого не работают мышь и клавиатура;
   - **Запись экрана и системного аудио (Screen Recording)** → включите **GoatDrey AI** — без этого скриншоты пустые (только обои);
   - при первом действии macOS спросит **«GoatDrey AI хочет управлять System Events»** → **«Разрешить»** (это в разделе «Автоматизация»);
   - микрофон для голосового ввода — macOS спросит сама при первом нажатии.
   После включения **перезапустите GoatDrey**. В **Настройки → Управление ПК** видно, какие разрешения уже есть, и есть кнопки, которые сразу открывают нужный раздел.
   > После каждого обновления macOS может «забыть» разрешения (подпись у программы самодельная). Если управление перестало работать — в «Универсальный доступ» удалите GoatDrey AI кнопкой «−» и включите заново.
5. Удалить: перетащите GoatDrey AI из «Программ» в Корзину. Данные лежат в `~/Library/Application Support/GoatDrey AI/`.

**Обновления на Mac.** Без подписи Apple тихое автообновление на Mac невозможно, поэтому GoatDrey сам проверяет новые релизы и показывает «Вышел GoatDrey X.Y» → **«Скачать»**: качает `.dmg` в «Загрузки» и открывает его — останется перетащить GoatDrey AI в «Программы» с заменой.

**Что умеет управление Mac:** клики (левый, правый, двойной) и перемещение мыши, прокрутка, набор текста (латиница — по-настоящему, кириллица и эмодзи — через буфер обмена, старое содержимое буфера возвращается), сочетания клавиш (`cmd+c`, `cmd+space`, `cmd+tab`, `ctrl+…`, `option+…`, F1–F12, стрелки), запуск и закрытие приложений по имени (понимает и «виндовые»: notepad → TextEdit, calc → Калькулятор, explorer → Finder), открытие ссылок, скриншоты. Ничего доустанавливать не нужно: всё через встроенные `osascript` (AppleScript/JXA) и `open`.

## Автономный режим «Компьютер» и безопасность

Выберите сверху режим **«Компьютер»** и напишите задачу обычными словами: «открой блокнот и напиши список покупок», «создай в Документах папку Отчёты и положи туда файл с итогами», «найди в браузере погоду на завтра». GoatDrey **сам** планирует и выполняет шаги: смотрит на экран (снимок + описание от vision-модели) → действует → проверяет результат — и в конце коротко отчитывается. Подтверждений на каждом шаге нет.

Это настройка **«Автономный режим»** (Настройки → Управление ПК), по умолчанию **включена**. Если выключить, GoatDrey будет спрашивать перед рискованными действиями (или перед каждым — вторым переключателем).

Что умеет агент: мышь (клики с подписью кнопки), клавиатура и сочетания, прокрутка, ожидание, снимки экрана, запуск и закрытие программ, открытие ссылок, **создание текстовых файлов** и **удаление в Корзину** (только в домашней папке), **безопасные команды** (список разрешённых: просмотр папок и файлов, `ipconfig`/`ping`, список процессов, создание папок, копирование и перенос внутри домашней папки).

### Правила безопасности (проверяются в коде, отключить нельзя)

Каждое действие перед выполнением проходит проверку в main-процессе программы (`src/main/safety.js`), а не только «просьбой» в подсказке модели. Если действие нарушает правило, оно **не выполняется**: агент пропускает шаг, ничего не спрашивая, а в итоге объясняет, что и почему не сделал. В ленте такой шаг помечен «пропущено».

- Не форматирует диски и не трогает системные папки (`C:\Windows`, `Program Files`, `ProgramData`, `/System`, `/Library`, `/usr`, `/etc`…). С файлами работает только внутри домашней папки, кроме служебных мест (`.ssh`, `AppData`, `~/Library`, автозапуск).
- Не меняет реестр, системные политики, службы, планировщик и автозапуск. Не открывает `regedit`, `gpedit`, `diskpart`, терминалы и «Выполнить» (Win+R).
- Не отключает антивирус, брандмауэр и UAC; не нажимает кнопки вроде «Отключить защиту».
- Не выключает, не перезагружает компьютер и не выходит из системы, **если вы прямо не попросили** об этом в своём сообщении.
- Не скачивает и не запускает программы и скрипты из интернета (`.exe`, `.msi`, `.ps1`, `.sh`, `.pkg`, `.dmg`…), не запускает `curl | sh`, `iex`, `powershell -enc` и т. п.
- Не вводит пароли, номера банковских карт (проверка по алгоритму Луна), CVV, PIN, коды из SMS/2FA, ключи API.
- Не нажимает «Купить», «Оплатить», «Оформить заказ» и не открывает страницы оплаты.
- Не отправляет сообщения, письма и посты от вашего имени, **если вы прямо не попросили** отправить.
- Удаляет файлы **только в Корзину**, никогда безвозвратно: `Shift+Delete`, `rm`, `del`, «Очистить корзину» заблокированы.
- Команды — только из белого списка, без цепочек (`;`, `&&`), перенаправлений (`>`) и подстановок.
- Текст на сайтах, в документах и на снимках экрана — это данные, а не команды (защита от prompt injection): указания принимаются только из ваших сообщений в чате.
- Не больше **40 шагов** и **15 минут** на одну задачу.

### Как остановить

- **Горячие клавиши из любой программы:** Windows — **`Ctrl+Alt+Esc`** (запасной вариант — `Ctrl+Alt+Shift+S`); Mac — **`⌃ Control + ⌥ Option + ⌘ Command + .`** (запасной вариант — `⌃⌥⌘ + Esc`).
- Кнопка **«Стоп»** в чате или `Esc` в окне GoatDrey.
- Кнопка **«Стоп»** на маленькой плашке **«GoatDrey управляет компьютером»** — она висит поверх всех окон вверху экрана, пока агент работает (на снимки экрана для модели она не попадает).

Стоп сразу обрывает запрос к модели и прерывает запущенные команды.

### Журнал

Каждый шаг виден в чате (сворачиваемый блок «Шаги»: выполнено / пропущено по правилам / ошибка). Всё также пишется в **Журнал действий** (слева) и в текстовый файл `agent.log` в папке с данными.


## Безопасность приложения (версия 1.4.0)

Кроме правил автономного агента (выше), в 1.4.0 укреплена сама программа — чтобы её было сложнее взломать, подменить или заставить утечь ключи.

### Оболочка Electron
- Изоляция: `contextIsolation`, без `nodeIntegration`, песочница (`sandbox: true`) на всех окнах, `webview` выключен.
- Строгий Content-Security-Policy: без `unsafe-eval` и без удалённых скриптов.
- Навигация и новые окна на внешние адреса блокируются. Ссылки открываются в системном браузере только по **https** и после проверки адреса.
- Разрешения (микрофон и т. п.) по умолчанию запрещены; микрофон включается только когда вы сами нажали голосовой ввод.
- IPC принимает запросы только от своего окна (проверяется `event.senderFrame`).
- [Electron Fuses](https://www.electronjs.org/docs/latest/tutorial/fuses): `RunAsNode` выключен, переменные `NODE_OPTIONS` и inspect-аргументы выключены, приложение грузится только из ASAR с проверкой целостности, cookies шифруются.
- Одновременно работает только один экземпляр программы.
- Electron обновлён до актуальной стабильной версии; зависимости ставятся через `npm ci` по зафиксированному `package-lock.json`.

### Ответы модели и вредоносный HTML
Текст модели и результаты поиска проходят через безопасный Markdown и [DOMPurify](https://github.com/cure53/DOMPurify): без `innerHTML` с «сырым» текстом, ссылки только https с `rel="noopener noreferrer"`.

### Агент и prompt injection
Результаты инструментов, веб-поиска и текст со снимка экрана в main-процессе помечаются как **UNTRUSTED DATA** — это данные, не команды. Правила `safety.js` исполняются только в main и из интерфейса их не обойти. В правилах закрыты типичные обходы: symlink и path traversal, переменные вроде `%WINDIR%` и `$env:TEMP`, unicode/RTLO, короткие имена `PROGRA~1`, потоки NTFS, экранирование белого списка команд. На это есть юнит-тесты (`scripts/test-safety.js`).

### Ключи и секреты
Ключи API хранятся только через `safeStorage` (шифрование средствами ОС: DPAPI в Windows, Связка ключей в macOS). Если шифрование недоступно, ключ **не записывается** открытым текстом. В журнал и в «Журнал действий» секреты не попадают (вычищаются). В настройках ключ показывается маской (последние 4 символа). Ключ отправляется только на свой хост провайдера и только по https (исключение — localhost для Ollama и LM Studio). Свой (custom) адрес проверяется по тем же правилам.

### Обновления и подпись кода
Автообновление берёт файлы **только** из репозитория `craor/GoatDrey-AI` по https. `electron-updater` проверяет **sha512** из `latest.yml`. На Mac скачанный `.dmg` тоже сверяется с sha512 из `latest-mac.yml`; при несовпадении файл отбрасывается.

**Подпись кода (Authenticode на Windows, Apple Developer на Mac) в этой сборке невозможна без платного сертификата.** Без неё:
- Windows может показывать предупреждение SmartScreen при первом запуске («неизвестный издатель»);
- macOS требует первый запуск через правый клик → «Открыть», а обновления не ставятся сами (только скачивание `.dmg`);
- нельзя включить проверку подписи обновления в `electron-updater` — иначе обновления перестанут ставиться.

Для Windows у открытых проектов есть бесплатный вариант: [SignPath](https://signpath.io/) (подписывает релизы open-source). Когда появится сертификат (свой или через SignPath), его нужно прописать в CI и тогда можно будет включить проверку подписи обновлений. На Mac для автоматических обновлений и Gatekeeper без обходных шагов нужен аккаунт Apple Developer (платный) и нотаризация.

### Локальные данные и пароль на вход
Файлы настроек, истории и журнала создаются с правами только для вас (`0600` / каталог `0700`, насколько это позволяет система). В **Настройках → Блокировка** можно включить пароль или PIN на запуск (по умолчанию выключено). Хранится только хэш **scrypt**, не сам пароль. После нескольких неверных попыток — пауза.

### Цепочка поставки и сообщения об уязвимостях
В CI: `npm ci`, тесты, `npm audit` (ошибка при high/critical), `check-no-keys`, сборка по тегу. Действия GitHub прибиты к хешам коммитов, права минимальные (`contents: write` только у job, который публикует релиз). Есть Dependabot и CodeQL. Как сообщить об уязвимости — в [SECURITY.md](SECURITY.md) (русский и английский).

## Репозиторий и автообновление

Исходники: **https://github.com/craor/GoatDrey-AI**.

### Как ставить из Releases
1. Откройте https://github.com/craor/GoatDrey-AI/releases.
2. В последнем релизе скачайте `GoatDrey-AI-Setup-<версия>.exe` (Windows) или `GoatDrey-AI-<версия>-mac-universal.dmg` (Mac) и установите (см. выше).
3. Файлы `latest.yml`, `latest-mac.yml` и `.blockmap` качать не нужно — их читает сама программа при обновлении.

### Как работает автообновление
GoatDrey сам проверяет релизы на GitHub при запуске и раз в 6 часов. **Токен не нужен.** Принимаются только файлы из репозитория `craor/GoatDrey-AI` по https, с проверкой **sha512** (`latest.yml` / `latest-mac.yml`). На Windows новая версия скачивается в фоне и ставится при перезапуске (или сразу — кнопкой в окне). На Mac программа без подписи Apple не может обновиться сама: GoatDrey скачает `.dmg`, сверит sha512 и откроет его — перетащите в «Программы» с заменой. Проверить вручную: **Настройки → Обновления → «Проверить обновления»**.

Подпись кода (Authenticode / Apple) в сборках нет — для неё нужен платный сертификат. Открытым Windows-проектам можно подписывать релизы через бесплатный [SignPath](https://signpath.io/). Подробнее — в разделе «Безопасность приложения» выше.

### Как выпустить новую версию (для разработчика)

**Проще всего — через GitHub Actions** (`.github/workflows/release.yml`): поднимите `"version"` в `package.json`, закоммитьте и запушьте тег:
```bash
git tag v1.2.1 && git push origin main v1.2.1
```
Actions сам соберёт Mac (`dmg` + `zip`, universal, на `macos-latest`) и Windows (`Setup.exe`, на `windows-latest`) и положит в релиз вместе с `latest.yml` и `latest-mac.yml`. Перед сборкой и после неё `scripts/check-no-keys.js` проверяет, что ни в исходниках, ни в собранной программе нет ключей API, — если что-то найдётся, сборка упадёт. Собрать Mac-версию на Linux/Windows нельзя — только на Mac (`npm run dist:mac`) или в Actions.

Вручную (только Windows):
1. Поднимите `"version"` в `package.json` (например, `1.1.1` → `1.1.2`). Обновление ставится, только если версия в релизе **больше** установленной.
2. Соберите: `npm run dist:win-installer` → в `release/` появятся `GoatDrey-AI-Setup-<версия>.exe`, `GoatDrey-AI-Setup-<версия>.exe.blockmap` и `latest.yml`.
3. Создайте релиз с тегом `v<версия>` и приложите **все три файла**:
   `gh release create v1.1.2 release/GoatDrey-AI-Setup-1.1.2.exe release/GoatDrey-AI-Setup-1.1.2.exe.blockmap release/latest.yml --repo craor/GoatDrey-AI --title "GoatDrey AI 1.1.2"`
   Или одной командой с публикацией: `GH_TOKEN=<токен с правом записи> npm run release:win` (создаст черновик релиза — его надо опубликовать на GitHub).
4. Релиз должен быть **опубликован** (не draft и не pre-release) — иначе клиенты его не увидят.

## Локальные модели: Ollama на своём ПК

1. Скачайте и установите Ollama: https://ollama.com/download (Windows, ~1 ГБ). После установки в трее появится значок ламы — значит, она работает (адрес `http://localhost:11434`).
   **На Mac:** https://ollama.com/download/mac — перетащите Ollama в «Программы» и запустите (лама появится в строке меню), или `brew install ollama`. На Apple Silicon модели работают на GPU через общую память: 16 ГБ — `qwen2.5:7b`, 32 ГБ и больше — `gpt-oss:20b`.
2. В GoatDrey: **Настройки → На этом компьютере → «Проверить»**. Появится статус «работает», объём вашей ОЗУ, видеокарта и совет, какую модель взять.
3. Нажмите **«Скачать»** у нужной модели — прогресс виден прямо в настройках (это то же самое, что `ollama pull` в консоли). Потом **«Использовать»** — и все чаты пойдут через ваш компьютер.

| Ваш компьютер | Какие модели брать |
|---|---|
| 8 ГБ ОЗУ, без видеокарты | `llama3.2:3b` (2 ГБ). Для проверки — `qwen2.5:0.5b` (0,4 ГБ), но она глуповата. |
| 16 ГБ ОЗУ или видеокарта 6–8 ГБ (RTX 3060/4060) | **`qwen2.5:7b`** (4,7 ГБ) — лучший старт, хорошо говорит по-русски и управляет ПК. Или `llama3.1:8b`. |
| Видеокарта 12 ГБ (RTX 3060 12G, 4070) | `qwen2.5vl:7b` (6 ГБ) — **видит картинки и скриншоты** (нужно режиму «Компьютер»), `qwen2.5:14b`. |
| Видеокарта 16–24 ГБ (RTX 4080/4090, 3090) | `gpt-oss:20b` (14 ГБ), `qwen2.5:32b` — почти как облако. |

- Модель должна **целиком помещаться в видеопамять** — тогда быстро. Не помещается — работает на процессоре, в 5–20 раз медленнее.
- Любую другую модель из https://ollama.com/library можно вписать в поле под списком и скачать.
- Модель для картинок и скриншотов: у скачанной vision-модели нажмите **«Для картинок»**.
- **LM Studio** тоже подходит: LM Studio → Developer → **Start Server** (адрес `http://localhost:1234/v1`), затем в GoatDrey у строки LM Studio — «Использовать».

## Любой ключ API

**Настройки → Где думать → «Добавить ключ API»**. Вставьте ключ — провайдер определится сам по началу ключа:

| Начало ключа | Провайдер | Где взять |
|---|---|---|
| `gsk_` | Groq (бесплатный тариф, свой веб-поиск, Whisper) | https://console.groq.com/keys |
| `sk-` | OpenAI (чат, картинки gpt-image-1 / DALL·E 3, Whisper) | https://platform.openai.com/api-keys |
| `xai-` | xAI / Grok (чат, картинки grok-2-image) | https://console.x.ai |
| `AIza` | Google Gemini (щедрый бесплатный лимит) | https://aistudio.google.com/apikey |
| `sk-ant-` | Anthropic / Claude (родной Messages API) | https://console.anthropic.com/settings/keys |
| `sk-or-` | OpenRouter (сотни моделей, есть бесплатные `:free`) | https://openrouter.ai/keys |
| `sk-api-` | MiniMax (чат, картинки image-01, **видео Hailuo**) | https://www.minimax.io/platform |
| — | DeepSeek, Mistral, Together (FLUX) — выберите в списке вручную | ссылки в окне ключа |
| — | **Свой (Custom)**: любой OpenAI-совместимый адрес (vLLM, LocalAI, прокси) | укажите «Адрес API» |

Нажмите **«Проверить»** (программа запросит список моделей) и **«Сохранить и включить»**. Профилей может быть сколько угодно; активный выбирается в списке моделей сверху (модели сгруппированы по провайдерам). Ключи хранятся только у вас, в `settings.json`, **в зашифрованном виде** (Electron safeStorage: DPAPI в Windows, Связка ключей в macOS). В самой программе и в репозитории ключей нет.

## Запуск из исходников

Нужен **Node.js 20 или новее** (https://nodejs.org, версия LTS).

```bat
cd goatdrey-ai
npm install
npm start
```

Если `npm start` пишет, что Electron не установлен (в новых npm установочные скрипты бывают отключены):

```bat
npm run fix:electron
npm start
```

### Собрать свой .exe на Windows

```bat
npm install
npm run dist:win            :: установщик GoatDrey-AI-Setup-<версия>.exe + portable в папке release\
npm run dist:win-installer  :: только установщик (NSIS: выбор папки, ярлыки в «Пуск» и на рабочем столе, удаление через «Параметры»)
npm run dist:win-portable   :: только portable
```

Иконка и сведения о версии вшиваются в `.exe` скриптом `scripts/after-pack.js` (чистый JS, `resedit`). На Windows установщик собирается как есть; на Linux/macOS для NSIS нужен `wine` в `PATH` (electron-builder запускает им сборку деинсталлятора), portable собирается и без него.

## Что умеет

| Функция | Как работает |
|---|---|
| **Чат** | Ответы печатаются в реальном времени (стриминг), Markdown, код с кнопкой «Копировать», таблицы. Виден «ход мысли» модели. |
| **История** | Все чаты сохраняются локально. Папки (чипы в сайдбаре, правый клик — переименовать/удалить), закрепление, поиск по названиям **и тексту** сообщений, автоназвание чата. |
| **Экспорт** | Меню чата `⋯` → «Экспорт в Markdown (.md)» или «в текст (.txt)». |
| **Поиск в интернете** | Режим «Поиск» или фраза «найди…» в обычном чате. Работает с **любой** моделью, и с локальной тоже: DuckDuckGo, Bing, Википедия без ключей, результаты подкладываются модели. С вашим ключом Groq — ещё и его собственный поиск. Под ответом — карточки источников. Если поиск недоступен, программа честно об этом скажет. |
| **Файлы и картинки** | Скрепка, перетаскивание или Ctrl+V. Текстовые файлы (txt, md, csv, json, код…) до 500 КБ уходят в контекст. Картинки смотрит модель, которая видит: у активного провайдера (GPT-4.1, Gemini, Claude, Grok, Pixtral…), локальная `qwen2.5vl:7b` или любая другая подключённая — выбирается автоматически. |
| **Голос** | Микрофон: нажали, сказали, нажали ещё раз — текст распознаёт Whisper (Groq, если есть его ключ, иначе OpenAI; без обоих — встроенное распознавание системы). «Озвучить» читает ответ голосом Windows (нужен русский голос: Параметры → Время и язык → Речь). |
| **Управление ПК** | Режим «Компьютер», **автономно**: задачу выполняет сам, от начала до конца (снимок экрана → действие → проверка). Работает с любым провайдером и с локальными моделями: если модель не умеет вызывать функции, программа сама переходит на текстовые JSON-команды. |
| **Безопасность** | Жёсткие правила в коде (см. «Автономный режим» выше): без паролей, оплаты, системных папок, реестра, отключения защиты, запуска скачанного, отправки сообщений без просьбы; удаление — только в Корзину. Стоп — `Ctrl+Alt+Esc` (Mac — `⌃⌥⌘ .`). Всё пишется в **Журнал действий** и `agent.log`. |
| **Шаблоны** | Готовые заготовки; `/` в пустом поле открывает список. Редактируются на странице «Шаблоны». |
| **Модели и режимы** | Выбор модели сверху справа (модели всех подключённых провайдеров и скачанные локальные, по группам). Режимы: Чат / Поиск / Компьютер. |
| **Фото и видео** | Картинки: OpenAI, xAI, MiniMax, Together (FLUX); 1–4 варианта, «ещё раз», «варианты». Видео: MiniMax Hailuo (2–6 минут). Всё сохраняется в галерею на диске. |
| **Настройки** | Тема (светлая / тёмная / как в системе), профили и ключи, локальные модели, модели, креативность, свои указания для всех чатов, поиск, управление ПК, голос, язык, автозапуск с Windows, папка с данными. |

### Горячие клавиши

На Mac вместо `Ctrl` — `⌘ Cmd`.

`Enter` — отправить · `Shift+Enter` — новая строка · `Ctrl+N` — новый чат · `Ctrl+K` — поиск по чатам · `Ctrl+B` — скрыть сайдбар · `Ctrl+,` — настройки · `/` — шаблоны · `Esc` — остановить ответ / закрыть окно · **`Ctrl+Alt+Esc`** (Mac — **`⌃⌥⌘ .`**) — аварийный стоп агента из любой программы.

## Фото и видео — честно

- **Картинки** рисуют OpenAI (`gpt-image-1`, `dall-e-3`), xAI (`grok-2-image`), MiniMax (`image-01`) и Together (`FLUX.1-schnell`, `FLUX.1-dev`). Добавьте ключ любого из них — форма на экране «Фото и видео» включится.
- **Видео** снимает MiniMax (`MiniMax-Hailuo-02`, `T2V-01`): задача ставится в очередь, программа опрашивает статус и скачивает mp4 (обычно 2–6 минут).
- Groq, Gemini, DeepSeek, Mistral, OpenRouter и **локальные модели Ollama картинки и видео не генерируют** — экран честно скажет, какой ключ нужен.
- Результаты лежат в `%APPDATA%\GoatDrey AI\media\`.

## Лимиты

Бесплатные тарифы (Groq, Gemini, OpenRouter) ограничивают число запросов в минуту и в день. Если упрётесь, программа так и скажет — выберите другую модель или провайдера сверху. У локальных моделей лимитов нет.

## Где лежат данные

Windows — `%APPDATA%\GoatDrey AI\`, Mac — `~/Library/Application Support/GoatDrey AI/`: `settings.json` (настройки и профили; ключи — только в зашифрованном виде через safeStorage), `lock.json` (хэш пароля на вход, если включили блокировку), `media\` (картинки и видео), `chats.json` (переписка), `templates.json`, `actions.log.json` и `agent.log` (журнал; секреты из него вычищаются). Файлы пишутся с правами только для вас. Кнопка «Папка с данными» в настройках открывает её.

## Структура проекта

```
src/main/        main-процесс Electron: ai.js (любой OpenAI-совместимый API), anthropic.js, providers.js (пресеты),
                 local.js (Ollama/LM Studio), media.js (картинки/видео), jsonactions.js, поиск, управление ПК (pc.js, pc-mac.js),
                 safety.js (правила безопасности агента), хранилище (store.js, ключи шифруются),
                 updater.js (автообновление из GitHub Releases)
src/renderer/    интерфейс (HTML/CSS/JS без сборщика), шрифты IBM Plex
assets/icon/     иконки приложения (из фото), icon.ico
assets/logo/     вторичный знак и словесный логотип (SVG)
prototype/       автономный прототип главного экрана
scripts/         make-icons.py, smoke-тесты, check-no-keys.js (проверка, что нигде нет ключей)
DESIGN.md        дизайн-концепция и система
```

## Сменить иконку

Положите фото в `assets/icon/source.jpg` и выполните `python scripts/make-icons.py` (нужен `pip install pillow`). Скрипт сделает квадратный кроп по лицу и все размеры + `icon.ico`.
